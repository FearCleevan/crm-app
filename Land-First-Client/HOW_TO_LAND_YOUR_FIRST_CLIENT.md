# How to Land Your First Client — Tactical Playbook

This is the step-by-step "do this exact thing" version. `GAME_PLAN.md` is the strategy; this is the checklist.

---

## 1. OnlineJobs.ph

- [ ] Create/update profile with a **specialist** title, not "Web Developer": e.g. *"Next.js Developer — Business Sites, Admin Systems & CRMs"*
- [ ] Profile summary structure:
  1. One line on who you help (SMBs needing a real system, not a template)
  2. 3 proof bullets: Acme Vintage Supply (full-stack e-commerce + admin + CMS, solo, ~7 weeks), Paul CRM (multi-tenant CRM SaaS), Kiosk POS project
  3. Link to portfolio (peterpaullazan.com) and Paul CRM (crm.peterpaullazan.com)
- [ ] Set availability to "immediately available" — you are
- [ ] Apply directly to any matching job posts daily — don't only rely on being found

---

## 2. Upwork

- [ ] Build profile around ONE primary category first (e.g. "Full Stack Web Development"), add others as secondary skills
- [ ] Portfolio items: add Acme Vintage Supply and Paul CRM as separate portfolio entries with 2–3 screenshots each and a one-paragraph description of what you built and the timeframe
- [ ] **First 1–2 jobs to bid on:** small, low-risk, fast-turnaround — Landing Page Sprint or a scoped Site Rescue fix. Price to win the review, not to profit.
- [ ] Proposal structure (see `OUTREACH_TEMPLATES.md` for the full template):
  1. First line: name the specific problem you saw in their listing
  2. One sentence: how you'd solve it
  3. One proof point matched to their need
  4. Clear next step ("happy to hop on a quick call" / "can start immediately")
- [ ] After 2–3 five-star reviews: start bidding on higher-ticket System Design / CRM / dashboard jobs — now Paul CRM is your lead proof

---

## 3. Indeed (bridge income)

- [ ] Search filters: remote, contract or full-time, keywords matching your actual stack (Next.js, React, full stack, SEO)
- [ ] Apply same-day to anything matching — don't over-filter, application volume matters more here than on freelance platforms
- [ ] Treat any offer as a floor, not a cage — contract/full-time work doesn't block freelancing on the side unless the contract explicitly says so (read that clause before signing)

---

## 4. Cold outreach (your own list)

### Building the list (20–30 prospects, hand-picked)
- [ ] Source individually: Google Maps ("antique shops," "boutique retailers," "local restaurants," whatever matches your case studies), LinkedIn, local business directories
- [ ] For each prospect, note ONE concrete, visible problem before reaching out: outdated design, broken mobile nav, no SEO basics, slow load, no online ordering, etc. — this is what makes the message personal instead of generic
- [ ] Load into Paul CRM's pipeline as you go — this is also a live demo of your own product if a prospect ever asks "what CRM do you use?"

### Sending
- [ ] Use the cold email/DM template in `OUTREACH_TEMPLATES.md`
- [ ] One message per prospect, personalized with the specific problem you noted
- [ ] Follow up once, 4–5 days later, if no reply — then move on, don't chase further

---

## 5. Closing the call/reply

When someone responds:
- [ ] Get on a call or async-clarify scope within 24–48 hours while interest is warm
- [ ] Confirm: what they need, rough budget range, timeline expectation
- [ ] Send a short written scope + price back within a day — speed matters more than a perfect proposal at this stage
- [ ] For the first 1–3 clients, bias toward closing the deal over maximizing price (see `PRICING_PACKAGES.md`) — reviews and a real testimonial are worth more than margin right now
