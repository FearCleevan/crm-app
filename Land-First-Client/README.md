## One standing rule, carried over from prior sessions

The 51,000-contact lead list (obtained secondhand via Brisk/Paul CRM, unverifiable provenance) is **not** part of this plan. It resurfaced multiple times across sessions reframed different ways ("throttled marketing," "cold outreach for web dev services") — the answer stays the same: CASL applies to commercial outreach regardless of framing or send rate, and a list with no verifiable consent chain is a real legal exposure, not a growth hack. The outreach strategy in this folder deliberately uses a small, hand-picked, individually-researched list instead — same tools, same infrastructure, legitimate list.
